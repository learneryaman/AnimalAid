Report injured/stray animals fast, track treatment transparently, and publish verified reports.

This is a ready-to-use prototype powered by browser geolocation (no location API) + optional AI assistance. Authentication can run with Firebase Auth (Google for People, Email/Password for NGO/Admin). Data is stored in Firestore when configured; otherwise it uses localStorage.

People Portal
  • • Camera/upload + AI triage suggestion
  • • Auto-fill coordinates via device location
  • • Request tracking with checkpoints
  • • Downloadable treatment report PDF
NGO / Hospital + Admin
  • • NGO: update checkpoints, edit treatment report
  • • NGO: weekly/monthly analytics + PDF export
  • • Admin: oversight dashboard, export/import, cleanup
Data persistence

If you configure Firebase in code, requests are stored in Firestore (sync across devices/users). If not configured, requests are stored in this browser only using localStorage.

People login
Google Auth only
Recommended

If Firebase config is not set in code, this uses Demo login instantly (no popup). For video recording, use the “One-click Demo Studio” panel.

Staff login
NGO / Hospital and Admin (Email + Password)

AI Helper (optional)
Used for: triage suggestions, report summaries, complaint writing assistance.
Bring your own key
Privacy note

If you use AI features with an API key, your prompt/image may be sent to OpenAI. For production, move AI calls to a secure backend so keys are not exposed.

Quick Demo Scenario (same browser)
  1. Login as People and create a new request with location.
  2. Sign out → Login as NGO and update checkpoints (Captured → Treatment → Released).
  3. Sign out → Login as People, open Completed Reports and download PDF.
One-click Demo Studio (for video)
Instantly open any portal and load sample requests. Works even without Firebase.
No setup
Tip for recording

Click “Load sample requests” → open NGO demo → mark a request as Captured/Treated/Released → open People demo → download the PDF from “Completed reports”.

Hardcoded Firebase config

To enable Firebase Auth + Firestore persistence, edit FIREBASE_CONFIG inside index.html. If left as placeholders, the app uses Demo auth and localStorage.

Required in Firebase Console
  • Authentication → enable Google and Email/Password
  • Firestore Database → create database + publish rules
  • Create staff users (NGO/Admin) in Authentication (Email/Password)
  • Add their emails to the hardcoded allowed lists in code
